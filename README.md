# Сервис учета топлива

Индивидуальный проект по дисциплине **«Технологии разработки приложений на базе фреймворков»**.

Проект предназначен для учета автомобилей, видов топлива, расхода топлива и заправок. Главная сущность проекта — `Refueling`.

## Текущее состояние

В ПР6 веб-интерфейс переведён с формирования HTML-строк в Python на систему шаблонов Django. View-функции получают данные, формируют контекст и вызывают `render()`, а HTML находится в шаблонах. Функция `page()` больше не используется.

Данные по-прежнему хранятся в JSON. Django ORM для предметной области ещё не используется. Формы создания и редактирования данных пока не реализованы; работа с базой данных относится к следующим практическим работам.

## Предметная область

- `Car` — автомобиль;
- `Fuel` — вид топлива;
- `Consumption` — расход топлива автомобиля;
- `Refueling` — заправка автомобиля.

`Refueling` связывает автомобиль и вид топлива, хранит количество топлива и цену за литр. Метод `calculate_cost()` рассчитывает стоимость заправки. `Consumption` связан с автомобилем и хранит расход в литрах на 100 км.

## Django-приложения

- `homepage` — главная страница, статические файлы и обработка 404;
- `cars` — список автомобилей и страница отдельного автомобиля;
- `fuels` — список видов топлива;
- `refuelings` — список заправок и страница отдельной заправки.

## Шаблоны Django

Общий шаблон: `templates/base.html`.

Дочерние страницы используют `{% extends "base.html" %}`. В базовом шаблоне используются блоки `title` и `content`.

Навигация вынесена в:

```text
templates/includes/navigation.html
```

Карточки объектов вынесены во включаемые шаблоны:

```text
cars/templates/cars/includes/car_card.html
refuelings/templates/refuelings/includes/refueling_card.html
```

## Контекст, циклы и условия

View-функции передают данные в шаблоны через словарь `context`. Для списков используются `{% for %}` и `{% empty %}`. Для страниц отдельных объектов и расхода используются `{% if %}`.

## Фильтры шаблонов

Используются фильтры `length`, `default` и `floatformat`.

## URL-маршрутизация

Для приложений настроены пространства имён через `app_name`. Ссылки в шаблонах формируются через `{% url %}`.

Основные страницы:

```text
/
/cars/
/cars/<id>/
/fuels/
/refuelings/
/refuelings/<id>/
```

Для несуществующих автомобилей и заправок возвращается HTTP-статус `404`.

## Статические файлы

```text
homepage/static/homepage/
├── css/style.css
├── img/logo.png
└── js/main.js
```

В `base.html` используется `{% load static %}`. Собственный CSS оформляет навигацию, карточки, логотип и контейнер страницы. JavaScript автоматически выводит текущий год в подвале.

## Хранение данных

```text
data/cars.json
data/fuels.json
data/consumptions.json
data/refuelings.json
```

Загрузка выполняется функциями `storage.py`. Django ORM для предметных сущностей пока не используется.
