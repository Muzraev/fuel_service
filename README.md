# Сервис учета топлива

## Назначение

Приложение предназначено для учета расхода топлива автомобиля. 
Пользователь может указать данные о поездке и получить информацию 
о расходе топлива и его стоимости.

## Целевая аудитория

Владельцы автомобилей.

## Предметная область

Предметная область проекта связана с учетом автомобилей, заправок, 
расхода топлива и затрат на топливо.

## Основные сущности

- пользователь;
- автомобиль;
- заправка;
- поездка;
- топливо.

## Основные функции

- расчет расхода топлива на 100 км;
- расчет стоимости потраченного топлива;
- оценка уровня расхода топлива;
- учет автомобилей;
- учет заправок и поездок.

## План развития

На следующих этапах планируется:

- расширение консольной версии программы;
- хранение информации об автомобилях и заправках;
- разработка веб-приложения на Django;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
