# Сервис учета топлива

Индивидуальный проект по дисциплине  
**«Технологии разработки приложений на базе фреймворков»**.

Проект представляет собой консольное приложение для учета заправок автомобилей, видов топлива и расхода топлива.

## Предметная область

Основные сущности проекта:

- автомобиль;
- заправка;
- топливо;
- расход топлива.

Главной сущностью проекта является **заправка**.

В рамках ПР3 проект был переработан из функциональной модели в объектно-ориентированную.

Для основных сущностей предметной области созданы отдельные классы:

- `Car` — автомобиль;
- `Fuel` — вид топлива;
- `Consumption` — расход топлива автомобиля;
- `Refueling` — заправка автомобиля.

## Возможности программы

Программа позволяет:

- добавлять автомобили;
- просматривать список автомобилей;
- добавлять виды топлива;
- просматривать виды топлива;
- указывать расход топлива автомобиля;
- просматривать расход автомобиля;
- рассчитывать необходимое количество топлива на заданное расстояние;
- добавлять заправки;
- просматривать все заправки;
- просматривать заправки выбранного автомобиля;
- рассчитывать стоимость отдельной заправки;
- рассчитывать общую стоимость всех заправок;
- сортировать заправки по стоимости.

## Объектная модель

### Car

Класс `Car` описывает автомобиль.

Основные атрибуты:

- `id` — идентификатор автомобиля;
- `name` — название автомобиля.

Класс реализует метод `__str__()`, который используется для удобного вывода информации об автомобиле.

Пример:

```python
car = Car(
    car_id=1,
    name='Audi A6'
)
```

Дополнительные функции модуля позволяют:

- добавлять автомобили;
- искать автомобиль по ID;
- искать автомобиль по названию;
- сортировать автомобили.

---

### Fuel

Класс `Fuel` описывает вид топлива.

Основные атрибуты:

- `id` — идентификатор вида топлива;
- `name` — название топлива.

Например:

```python
fuel = Fuel(
    fuel_id=1,
    name='АИ-95'
)
```

Класс содержит метод `__str__()` для строкового представления объекта.

Дополнительные функции позволяют:

- добавлять виды топлива;
- искать топливо по ID;
- искать топливо по названию;
- сортировать виды топлива.

---

### Consumption

Класс `Consumption` описывает расход топлива конкретного автомобиля.

Основные атрибуты:

- `id` — идентификатор записи о расходе;
- `car` — объект класса `Car`;
- `liters_per_100km` — расход топлива в литрах на 100 км.

Например:

```python
consumption = Consumption(
    consumption_id=1,
    car=car,
    liters_per_100km=8.5
)
```

Основной метод:

```python
calculate_fuel_for_distance()
```

Метод рассчитывает количество топлива, необходимое автомобилю для прохождения заданного расстояния.

Например, если расход автомобиля составляет `8.5 л/100 км`, то для расстояния `200 км` потребуется:

```text
17 литров
```

Также класс реализует метод `__str__()`.

---

### Refueling

Класс `Refueling` является главной сущностью проекта и описывает конкретную заправку автомобиля.

Основные атрибуты:

- `id` — идентификатор заправки;
- `car` — объект класса `Car`;
- `fuel` — объект класса `Fuel`;
- `fuel_liters` — количество заправленного топлива;
- `price_per_liter` — стоимость одного литра топлива.

Пример:

```python
refueling = Refueling(
    refueling_id=1,
    car=car,
    fuel=fuel,
    fuel_liters=40,
    price_per_liter=65
)
```

Основной метод:

```python
calculate_cost()
```

Он рассчитывает полную стоимость заправки:

```text
40 л × 65 руб. = 2600 руб.
```

Класс также реализует метод `__str__()` для удобного вывода информации.

Дополнительные функции позволяют:

- добавлять заправки;
- искать заправки конкретного автомобиля;
- искать заправки по виду топлива;
- сортировать заправки по стоимости;
- рассчитывать общую стоимость всех заправок.

## Взаимодействие объектов

В проекте объекты связаны друг с другом.

Объект `Consumption` содержит ссылку на объект `Car`:

```python
consumption.car
```

Объект `Refueling` содержит ссылки сразу на два объекта:

```python
refueling.car
refueling.fuel
```

Таким образом, заправка связана с конкретным автомобилем и конкретным видом топлива.

Пример взаимодействия:

```python
car = Car(1, 'Audi A6')
fuel = Fuel(1, 'АИ-95')

refueling = Refueling(
    1,
    car,
    fuel,
    40,
    65
)

print(refueling.car.name)
print(refueling.fuel.name)
print(refueling.calculate_cost())
```

Результат:

```text
Audi A6
АИ-95
2600
```

## Назначение основных файлов

`main.py` — содержит консольное меню и основную логику взаимодействия пользователя с приложением.

`storage.py` — отвечает за загрузку и сохранение данных в JSON-файлы.

`utils.py` — содержит вспомогательные функции для ввода данных.

`models/cars.py` — содержит класс `Car` и функции работы с автомобилями.

`models/fuels.py` — содержит класс `Fuel` и функции работы с видами топлива.

`models/consumptions.py` — содержит класс `Consumption` и функции работы с расходом топлива.

`models/refueling.py` — содержит главный класс `Refueling` и функции работы с заправками.

Папка `data` используется для хранения данных.

Папка `tests` содержит автоматические тесты проекта.

## Что изменилось в ПР3

В ПР2 проект использовал преимущественно функциональный подход.

В ПР3 основные сущности предметной области были преобразованы в классы и объекты.

Были созданы классы:

```text
Car
Fuel
Consumption
Refueling
```

В классах реализованы:

- конструкторы `__init__()`;
- атрибуты объектов;
- методы объектов;
- строковое представление `__str__()`;
- аннотации типов.

Организовано взаимодействие объектов.

Загрузка и сохранение JSON были адаптированы к объектной модели.

Автоматические тесты были переработаны для работы с объектами.

Структура проекта была изменена: модели предметной области вынесены в отдельную папку `models`.

Файл `README.md` обновлен в соответствии с текущим состоянием проекта.
