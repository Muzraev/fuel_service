# Сервис учета топлива

Индивидуальный проект по дисциплине программирование на Python.

Проект предназначен для учета заправок автомобилей, видов топлива и расхода топлива.

## Предметная область

Основные сущности проекта:

- `Refueling` — заправка автомобиля, главная сущность проекта;
- `Car` — автомобиль;
- `Fuel` — вид топлива;
- `Consumption` — расход топлива автомобиля.

Заправка связывает автомобиль и вид топлива, хранит количество топлива и цену за литр.

Расход хранится отдельно для каждого автомобиля в литрах на 100 км.

## Возможности программы

Программа позволяет:

- добавлять автомобили;
- добавлять виды топлива;
- указывать расход автомобиля;
- добавлять заправки;
- просматривать все заправки;
- просматривать заправки конкретного автомобиля;
- рассчитывать стоимость заправки;
- рассчитывать общую стоимость заправок;
- сортировать заправки по стоимости;
- рассчитывать необходимое количество топлива на заданное расстояние.
