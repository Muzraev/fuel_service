# Сервис учета топлива

Индивидуальный проект по дисциплине  
**«Технологии разработки приложений на базе фреймворков»**.

Проект предназначен для учета автомобилей, топлива, расхода топлива и заправок.

В ПР3 проект был преобразован в объектно-ориентированную модель.

В ПР5 консольное приложение дополнено веб-интерфейсом на Django.

## Предметная область

Основные сущности проекта:

- `Car` — автомобиль;
- `Fuel` — вид топлива;
- `Consumption` — расход топлива автомобиля;
- `Refueling` — заправка автомобиля.

Главной сущностью проекта является `Refueling`.

Заправка связывает автомобиль с видом топлива и содержит информацию о количестве топлива, цене за литр и полной стоимости заправки.

Расход топлива связан с конкретным автомобилем и хранится в литрах на 100 км.

## Объектная модель

### Car

Класс автомобиля.

Основные атрибуты:

- `id`;
- `name`.

### Fuel

Класс вида топлива.

Основные атрибуты:

- `id`;
- `name`.

### Consumption

Класс расхода топлива автомобиля.

Основные атрибуты:

- `id`;
- `car`;
- `liters_per_100km`.

Метод:

```python
calculate_fuel_for_distance()
```

рассчитывает необходимое количество топлива на заданное расстояние.

### Refueling

Главная сущность проекта.

Основные атрибуты:

- `id`;
- `car`;
- `fuel`;
- `fuel_liters`;
- `price_per_liter`.

Метод:

```python
calculate_cost()
```

рассчитывает стоимость заправки.

## Маршрутизация

В проекте используется двухуровневая маршрутизация Django.

Корневые маршруты находятся в:

```text
fuel_service_web/urls.py
```

Маршруты отдельных приложений находятся в:

```text
homepage/urls.py
cars/urls.py
fuels/urls.py
refuelings/urls.py
```

Для подключения маршрутов приложений используется функция `include()`.

Для страниц отдельных объектов используются динамические URL с конвертером `int`.

Пример:

```python
path(
    '<int:refueling_id>/',
    views.refueling_detail,
    name='refueling_detail'
)
```

## Установка и запуск

Создать виртуальное окружение:

```powershell
python -m venv .venv
```

Активировать:

```powershell
.\.venv\Scripts\Activate.ps1
```

Установить зависимости:

```powershell
pip install -r requirements.txt
```

Применить встроенные миграции Django:

```powershell
python manage.py migrate
```

Проверить Django-проект:

```powershell
python manage.py check
```

Запустить веб-приложение:

```powershell
python manage.py runserver
```

После запуска открыть:

```text
http://127.0.0.1:8000/
```
