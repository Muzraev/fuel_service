# Сервис учета топлива

## Описание проекта

Сервис учета топлива — консольное приложение на Python для учета автомобилей, поездок и заправок.

Проект разработан с использованием объектно-ориентированного программирования.

## Основные классы

### Car

Класс представляет автомобиль.

Атрибуты:

- `id` — идентификатор автомобиля;
- `name` — название автомобиля.

Методы:

- `__init__()` — создание объекта;
- `__str__()` — строковое представление автомобиля.

### Trip

Класс представляет поездку автомобиля.

Атрибуты:

- `id` — идентификатор поездки;
- `car` — объект автомобиля;
- `distance_km` — пройденное расстояние;
- `fuel_liters` — количество потраченного топлива.

Методы:

- `calculate_consumption()` — расчет расхода топлива на 100 км;
- `get_consumption_status()` — определение уровня расхода;
- `__str__()` — строковое представление поездки.

### Refueling

Класс представляет заправку автомобиля.

Атрибуты:

- `id` — идентификатор заправки;
- `car` — объект автомобиля;
- `fuel_liters` — количество топлива;
- `price_per_liter` — цена одного литра.

Методы:

- `calculate_cost()` — расчет стоимости заправки;
- `__str__()` — строковое представление заправки.

## Взаимодействие объектов

Объекты `Trip` и `Refueling` связаны с объектом `Car`.

Пример:

```python
car = Car(1, 'Audi')

trip = Trip(
    1,
    car,
    200,
    20
)

refueling = Refueling(
    1,
    car,
    30,
    65
)
```

Название автомобиля можно получить через связанные объекты:

```python
trip.car.name
refueling.car.name
```

## Возможности программы

Программа позволяет:

- добавлять автомобили;
- искать автомобили;
- сортировать автомобили;
- добавлять поездки;
- рассчитывать расход топлива;
- определять уровень расхода;
- искать поездки автомобиля;
- рассчитывать средний расход;
- сортировать поездки по расходу;
- добавлять заправки;
- рассчитывать стоимость заправки;
- просматривать заправки автомобиля;
- сохранять данные в JSON-файлы.

## Хранение данных

Для хранения данных используются JSON-файлы.

При загрузке данные из JSON преобразуются в объекты `Car`, `Trip` и `Refueling`.

В файлах поездок и заправок хранится `car_id`, а после загрузки программа находит соответствующий объект `Car`.

## Запуск программы

Установить зависимости:

```bash
pip install -r requirements.txt
```

Запустить приложение:

```bash
python main.py
```
