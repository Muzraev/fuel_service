# Сервис учета топлива

## Описание проекта

Сервис учета топлива — консольное приложение на Python для учета автомобилей и поездок.

Программа позволяет хранить информацию об автомобилях, добавлять поездки, рассчитывать расход топлива и стоимость поездки.

## Предметная область

Предметная область проекта — учет автомобилей, поездок и расхода топлива.

Основные сущности:

- автомобиль;
- поездка;
- топливо.

## Возможности программы

Программа позволяет:

- добавлять автомобили;
- просматривать список автомобилей;
- искать автомобили по названию;
- добавлять поездки;
- просматривать поездки;
- искать поездки определенного автомобиля;
- рассчитывать расход топлива на 100 км;
- рассчитывать стоимость потраченного топлива;
- определять уровень расхода топлива;
- рассчитывать средний расход топлива;
- сортировать поездки по расходу топлива;
- сохранять данные в JSON-файлы.
